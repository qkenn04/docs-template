# Cấu trúc backend NestJS

Chọn topic này khi project dùng NestJS. Nó tạo [mẫu `docs/dev/backend-nestjs.md`](files/docs/dev/backend-nestjs.md), mô tả cách tổ chức module, phụ thuộc, test và hợp đồng API; không tạo mã NestJS.

```bash
docs-template/scripts/new-project-docs.sh --topic backend/nestjs standard ../my-app "My App"
```

Điền quyết định của project về database, giao diện API, xác thực và vận hành. Mẫu tham chiếu các file tài liệu của hồ sơ `standard` hoặc `full`.
