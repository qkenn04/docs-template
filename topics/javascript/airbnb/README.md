# JavaScript/TypeScript conventions chọn lọc từ Airbnb

Chọn topic này cho project JavaScript hoặc TypeScript muốn có hướng dẫn chung về cách viết code.

Nó thêm [mẫu quy ước JavaScript/TypeScript](files/docs/dev/javascript-conventions.md) vào `docs/dev/javascript-conventions.md`. Đây là bộ quy tắc chọn lọc lấy Airbnb Style Guide làm nguồn tham khảo, không phải bản sao đầy đủ và không yêu cầu cài `eslint-config-airbnb`.

```bash
docs-template/scripts/new-project-docs.sh --topic javascript/airbnb standard ../my-app "My App"
```

Topic chỉ thêm tài liệu. Project cần cấu hình ESLint, TypeScript và formatter riêng, rồi điền các lệnh kiểm tra thật. File đã tồn tại được giữ nguyên; so sánh và cập nhật thủ công nếu muốn nhận bản mẫu mới.
